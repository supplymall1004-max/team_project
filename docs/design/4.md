## 전체 레이아웃 구조

### 헤더 (Header)
- **위치**: 페이지 최상단 고정
- **구성 요소**:
  - 좌측: Qshop 로고
  - 중앙/우측: 메인 네비게이션 메뉴
  - 우측: "무료로 시작하기" CTA 버튼
- **스타일**: 깔끔한 흰색 배경, 미니멀 디자인
- **고정 여부**: 스크롤 시 상단 고정 (Sticky Header)

### 메인 컨텐츠 영역
- **레이아웃**: 세로 스크롤 구조
  1. 히어로 섹션 (Hero Section)
  2. 기능 소개 섹션
  3. 템플릿 갤러리 섹션
  4. 고객 후기 섹션
  5. 최종 CTA 섹션
- **배경**: 흰색/연한 회색 교차 사용, 그라데이션 배경 활용

## 네비게이션 시스템

### 메인 네비게이션 구조
```
로고 | 템플릿 | 기능 | 가격 | 블로그 | 고객센터 | 무료로 시작하기
```

### 네비게이션 특징
- **스타일**: 미니멀, 깔끔한 디자인
- **호버 효과**: 텍스트 색상 변경 또는 밑줄
- **활성 상태**: 현재 페이지 강조 표시
- **모바일**: 햄버거 메뉴로 전환
- **드롭다운**: 일부 메뉴에 하위 카테고리 제공

## 인터랙티브 요소

### 슬라이더 기능
```javascript
// 템플릿 슬라이더
class TemplateSlider {
  constructor(container) {
    this.container = container;
    this.slides = container.querySelectorAll('.template-card');
    this.currentIndex = 0;
    this.totalSlides = this.slides.length;
    this.init();
  }
  
  init() {
    this.showSlide(this.currentIndex);
    this.setupControls();
    this.autoSlide();
  }
  
  showSlide(index) {
    this.slides.forEach((slide, i) => {
      slide.style.display = i >= index && i < index + 3 ? 'block' : 'none';
    });
  }
  
  nextSlide() {
    this.currentIndex = (this.currentIndex + 3) % this.totalSlides;
    this.showSlide(this.currentIndex);
  }
  
  prevSlide() {
    this.currentIndex = (this.currentIndex - 3 + this.totalSlides) % this.totalSlides;
    this.showSlide(this.currentIndex);
  }
  
  setupControls() {
    const nextBtn = this.container.querySelector('.slider-next');
    const prevBtn = this.container.querySelector('.slider-prev');
    
    if (nextBtn) nextBtn.addEventListener('click', () => this.nextSlide());
    if (prevBtn) prevBtn.addEventListener('click', () => this.prevSlide());
  }
  
  autoSlide() {
    setInterval(() => {
      this.nextSlide();
    }, 5000);
  }
}

// 고객 후기 슬라이더
class TestimonialSlider {
  constructor(container) {
    this.container = container;
    this.slides = container.querySelectorAll('.testimonial-card');
    this.dots = container.querySelectorAll('.dot');
    this.currentIndex = 0;
    this.init();
  }
  
  init() {
    this.showSlide(this.currentIndex);
    this.setupDots();
    this.autoSlide();
  }
  
  showSlide(index) {
    this.slides.forEach((slide, i) => {
      slide.style.display = i === index ? 'block' : 'none';
    });
    
    this.dots.forEach((dot, i) => {
      dot.classList.toggle('active', i === index);
    });
  }
  
  goToSlide(index) {
    this.currentIndex = index;
    this.showSlide(this.currentIndex);
  }
  
  nextSlide() {
    this.currentIndex = (this.currentIndex + 1) % this.slides.length;
    this.showSlide(this.currentIndex);
  }
  
  setupDots() {
    this.dots.forEach((dot, i) => {
      dot.addEventListener('click', () => this.goToSlide(i));
    });
  }
  
  autoSlide() {
    setInterval(() => {
      this.nextSlide();
    }, 4000);
  }
}
```
