## 전체 레이아웃 구조

### 헤더 (Header)
- **위치**: 페이지 최상단
- **구성 요소**:
  - 좌측: 아임웹 로고
  - 중앙/우측: 메인 네비게이션 메뉴
  - 우측: 로그인, 무료 체험 버튼
- **스타일**: 깔끔한 흰색 배경, 미니멀 디자인
- **고정 여부**: 스크롤 시 상단 고정 가능 (Sticky Header)

### 메인 컨텐츠 영역
- **레이아웃**: 세로 스크롤 구조
  1. 히어로 섹션 (Hero Section)
  2. 카테고리 필터 바
  3. 템플릿 그리드 섹션
  4. 하단 CTA 섹션 (3개 카드)
- **배경**: 주로 흰색, 섹션별로 연한 회색 배경 교차 사용

## 네비게이션 시스템

### 메인 네비게이션 구조
```
로고 | 템플릿 | 기능 | 가격 | 고객지원 | 로그인 | 무료체험
```

### 네비게이션 특징
- **스타일**: 미니멀, 깔끔한 디자인
- **호버 효과**: 텍스트 색상 변경 또는 밑줄
- **활성 상태**: 현재 페이지 강조 표시
- **모바일**: 햄버거 메뉴로 전환

## 히어로 섹션

### 구조
```
[배경 이미지 또는 그라데이션]

    "브랜드를 쉽고 아름답게"
    
    "템플릿으로 만들어 보세요"
    
    "디자인 경험 없이도 누구나 활용 가능한 템플릿을 준비했어요"
    
    [CTA 버튼: 무료 체험 시작하기]
```

### 디자인 특징
- **배경**: 이미지 또는 그라데이션 배경
- **텍스트 정렬**: 중앙 정렬
- **타이포그래피**: 큰 헤딩으로 시각적 임팩트
- **CTA 버튼**: 눈에 띄는 Primary 버튼

### 인터랙티브 효과

#### 필터 애니메이션
```javascript
// 필터 클릭 시 템플릿 필터링
function filterTemplates(category) {
  const templates = document.querySelectorAll('.template-card');
  
  templates.forEach(card => {
    const cardCategory = card.dataset.category;
    
    if (category === 'all' || cardCategory === category) {
      card.style.display = 'block';
      card.style.animation = 'fadeIn 0.3s ease';
    } else {
      card.style.display = 'none';
    }
  });
}

@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

#### 무한 스크롤
```javascript
// 스크롤 시 추가 템플릿 로드
let page = 1;
const loadMoreTemplates = async () => {
  const response = await fetch(`/api/templates?page=${page}&category=${currentCategory}`);
  const templates = await response.json();
  
  appendTemplates(templates);
  page++;
};

window.addEventListener('scroll', () => {
  if (window.innerHeight + window.scrollY >= document.body.offsetHeight - 1000) {
    loadMoreTemplates();
  }
});
```

### JavaScript 기능
```javascript
// 필터 기능
document.querySelectorAll('.filter-button').forEach(button => {
  button.addEventListener('click', function() {
    // 활성 상태 변경
    document.querySelectorAll('.filter-button').forEach(btn => {
      btn.classList.remove('active');
    });
    this.classList.add('active');
    
    // 필터링
    const category = this.dataset.category;
    filterTemplates(category);
  });
});

function filterTemplates(category) {
  const templates = document.querySelectorAll('.template-card');
  let visibleCount = 0;
  
  templates.forEach(card => {
    const cardCategory = card.dataset.category;
    
    if (category === 'all' || cardCategory === category) {
      card.style.display = 'block';
      card.style.animation = 'fadeIn 0.3s ease';
      visibleCount++;
    } else {
      card.style.display = 'none';
    }
  });
  
  // 결과가 없을 때 메시지 표시
  if (visibleCount === 0) {
    showNoResultsMessage();
  } else {
    hideNoResultsMessage();
  }
}

// 페이드 인 애니메이션
const style = document.createElement('style');
style.textContent = `
  @keyframes fadeIn {
    from {
      opacity: 0;
      transform: translateY(10px);
    }
    to {
      opacity: 1;
      transform: translateY(0);
    }
  }
`;
document.head.appendChild(style);

// 무한 스크롤
let currentPage = 1;
let isLoading = false;
let hasMore = true;

async function loadMoreTemplates() {
  if (isLoading || !hasMore) return;
  
  isLoading = true;
  document.getElementById('loadingIndicator').style.display = 'block';
  
  try {
    const activeCategory = document.querySelector('.filter-button.active').dataset.category;
    const response = await fetch(`/api/templates?page=${currentPage}&category=${activeCategory}`);
    const data = await response.json();
    
    if (data.templates.length === 0) {
      hasMore = false;
    } else {
      appendTemplates(data.templates);
      currentPage++;
    }
  } catch (error) {
    console.error('템플릿 로드 실패:', error);
  } finally {
    isLoading = false;
    document.getElementById('loadingIndicator').style.display = 'none';
  }
}

function appendTemplates(templates) {
  const grid = document.getElementById('templateGrid');
  
  templates.forEach(template => {
    const card = createTemplateCard(template);
    grid.appendChild(card);
  });
}

function createTemplateCard(template) {
  const card = document.createElement('div');
  card.className = 'template-card';
  card.dataset.category = template.category;
  
  card.innerHTML = `
    <div class="template-thumbnail">
      <img src="${template.thumbnail}" alt="${template.name}" loading="lazy">
    </div>
    <div class="template-name">${template.name}</div>
  `;
  
  card.addEventListener('click', () => {
    window.location.href = `/template/${template.id}`;
  });
  
  return card;
}

// 스크롤 이벤트
window.addEventListener('scroll', () => {
  const scrollHeight = document.documentElement.scrollHeight;
  const scrollTop = document.documentElement.scrollTop;
  const clientHeight = document.documentElement.clientHeight;
  
  if (scrollTop + clientHeight >= scrollHeight - 1000) {
    loadMoreTemplates();
  }
});

// 이미지 lazy loading
if ('IntersectionObserver' in window) {
  const imageObserver = new IntersectionObserver((entries, observer) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        const img = entry.target;
        img.src = img.dataset.src;
        img.classList.remove('lazy');
        observer.unobserve(img);
      }
    });
  });
  
  document.querySelectorAll('img[data-src]').forEach(img => {
    imageObserver.observe(img);
  });
}
```
