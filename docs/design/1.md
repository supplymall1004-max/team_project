## 전체 레이아웃 구조

### 헤더 (Header)
- **위치**: 페이지 최상단 고정
- **구성 요소**:
  - 좌측: 로고/브랜드명
  - 중앙: 메인 네비게이션 메뉴
  - 우측: 로그인 버튼, 무료 체험 시작 버튼
- **스타일**: 깔끔한 흰색 배경, 그림자 효과로 깊이감 제공
- **고정 여부**: 스크롤 시 상단 고정 (Sticky Header)

### 메인 컨텐츠 영역
- **레이아웃**: 섹션 기반 세로 스크롤 구조
- **섹션 간격**: 충분한 여백으로 가독성 확보
- **배경**: 흰색/연한 회색 교차 사용

## 버튼 및 CTA 요소

### 주요 버튼 타입

#### 1. Primary CTA 버튼
```css
/* "Get started" / "Start a Free Trial" 버튼 */
- 배경색: 진한 색상 (브랜드 컬러)
- 텍스트: 흰색
- 크기: 중간~큰 사이즈
- 패딩: 상하 12-16px, 좌우 24-32px
- 보더 라디우스: 4-6px
- 호버 효과: 배경색 약간 어둡게, 약간 확대 효과
- 폰트: 볼드, 16-18px
```

#### 2. Secondary 버튼
```css
/* "Log In" 버튼 */
- 배경색: 투명 또는 흰색
- 텍스트: 진한 색상
- 보더: 1-2px 실선
- 호버 효과: 배경색 채우기 또는 보더 색상 변경
```

#### 3. 텍스트 링크 버튼
```css
/* "Explore →" 형태 */
- 텍스트: 브랜드 컬러
- 화살표 아이콘: 인라인 또는 ::after 가상 요소
- 호버 효과: 밑줄 또는 색상 변경
```

#### 4. 카드 내부 CTA
```css
/* 각 기능 섹션의 "Explore →" 버튼 */
- 위치: 카드 하단 또는 섹션 하단
- 스타일: 텍스트 링크 + 화살표
- 정렬: 우측 정렬 또는 중앙 정렬
```

### 버튼 배치 전략
- **상단 헤더**: 우측에 Primary CTA 배치
- **히어로 섹션**: 중앙 또는 좌측에 큰 Primary CTA
- **기능 소개 섹션**: 각 카드 하단에 Secondary CTA
- **푸터**: 여러 Secondary CTA 링크

## 색상 및 타이포그래피

### 색상 팔레트
```css
/* 추정 색상 체계 */
Primary Color: #000000 (검정) 또는 진한 네이비
Secondary Color: 브랜드 컬러 (파란색 계열)
Background: #FFFFFF (흰색)
Background Alt: #F5F5F5 (연한 회색)
Text Primary: #000000 또는 #1a1a1a
Text Secondary: #666666 (회색)
Accent: 브랜드 컬러 (CTA 버튼용)
```

### 타이포그래피
```css
/* 헤딩 */
H1: 48-64px, Bold, Line-height: 1.2
H2: 36-48px, Bold, Line-height: 1.3
H3: 24-32px, Semi-bold, Line-height: 1.4
H4: 20-24px, Medium, Line-height: 1.5

/* 본문 */
Body Large: 18-20px, Regular, Line-height: 1.6
Body: 16px, Regular, Line-height: 1.6
Body Small: 14px, Regular, Line-height: 1.5

/* 버튼 */
Button Text: 16-18px, Semi-bold 또는 Bold
```

### 폰트 스택
- **Sans-serif**: 주로 사용 (예: Inter, Helvetica, Arial)
- **Serif**: 특정 섹션에서 강조용으로 사용 가능

## 섹션 구성 및 콘텐츠 구조

### 1. 히어로 섹션 (Hero Section)
```
구성:
- 대형 헤딩: "The leader in website design"
- 서브 텍스트: 간단한 설명
- Primary CTA 버튼: "Get started"
- 배경: 이미지 또는 그라데이션
- 높이: 뷰포트 높이의 60-80%
```

### 2. 기능 소개 섹션
```
구성:
- 섹션 제목 (H2)
- 4-6개의 카드 그리드 레이아웃
- 각 카드:
  * 아이콘 또는 이미지
  * 제목 (H3)
  * 설명 텍스트
  * "Explore →" 링크
- 그리드: 2-3열 (데스크톱), 1열 (모바일)
```

### 3. Design Intelligence 섹션
```
구성:
- 대형 제목: "Build a bespoke website with Design Intelligence"
- 4개의 기능 카드:
  1. Tailored to you (AI 맞춤화)
  2. Edit with drag-and-drop (드래그 앤 드롭)
  3. Preview alternate styles (스타일 미리보기)
  4. Draft copy automatically (AI 텍스트 생성)
- 각 카드에 이미지/아이콘 포함
- "Explore Design Intelligence →" CTA
```

### 4. Creative Tools 섹션
```
구성:
- 섹션 제목
- 4개의 기능 설명:
  1. Look great on every device (반응형)
  2. Support all your media (미디어 관리)
  3. Engage with motion (모션 효과)
  4. Amplify your visual appeal (시각 효과)
- 각 항목에 스크린샷 또는 GIF 포함
```

### 5. SEO & Analytics 섹션
```
구성:
- 3개의 카드:
  1. SEO tools
  2. Integrations and extensions
  3. Website analytics
- 각 카드에 아이콘과 간단한 설명
```

### 6. 추가 기능 섹션

### 7. How-to 섹션

### 8. 지원 섹션

## 인터랙티브 요소

### 1. 호버 효과
```css
/* 카드 호버 */
- 약간의 상승 효과 (transform: translateY(-4px))
- 그림자 강화 (box-shadow 증가)
- 전환 시간: 0.3s ease

/* 버튼 호버 */
- 배경색 변경
- 약간의 확대 (scale: 1.05)
- 커서: pointer
```

### 2. 스크롤 애니메이션
- **Fade-in**: 섹션이 뷰포트에 들어올 때 페이드 인
- **Slide-up**: 아래에서 위로 슬라이드
- **Intersection Observer API** 사용 추정

### 3. 이미지 갤러리/캐러셀
- 템플릿 미리보기 이미지
- 자동 슬라이드 또는 수동 네비게이션
- 썸네일 네비게이션

### 4. 모달/오버레이
- 할인 코드 입력 모달
- 템플릿 상세 보기 모달
- 로그인/회원가입 모달

### 5. 드롭다운 메뉴
- 네비게이션 메가 메뉴
- 언어 선택 드롭다운
- 통화 선택 드롭다운

## 반응형 디자인

### 브레이크포인트
```css
/* 모바일 */
@media (max-width: 768px) {
  - 1열 레이아웃
  - 햄버거 메뉴
  - 버튼 전체 너비
  - 폰트 크기 20-30% 감소
  - 이미지 최적화
}

/* 태블릿 */
@media (min-width: 769px) and (max-width: 1024px) {
  - 2열 그리드
  - 네비게이션 축소
}

/* 데스크톱 */
@media (min-width: 1025px) {
  - 3-4열 그리드
  - 전체 네비게이션 표시
  - 최대 너비: 1200-1400px
}
```

### 모바일 최적화 요소
- 터치 친화적 버튼 크기 (최소 44x44px)
- 가로 스크롤 방지
- 이미지 lazy loading
- 텍스트 가독성 확보

### JavaScript 기능 예시
```javascript
// 드롭다운 메뉴
document.querySelectorAll('.nav-item.dropdown').forEach(item => {
  item.addEventListener('mouseenter', () => {
    const dropdown = item.querySelector('.dropdown-menu');
    if (dropdown) {
      dropdown.style.display = 'block';
    }
  });
  
  item.addEventListener('mouseleave', () => {
    const dropdown = item.querySelector('.dropdown-menu');
    if (dropdown) {
      dropdown.style.display = 'none';
    }
  });
});

// 스크롤 애니메이션
const observerOptions = {
  threshold: 0.1,
  rootMargin: '0px 0px -50px 0px'
};

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('fade-in');
    }
  });
}, observerOptions);

document.querySelectorAll('.feature-card, .section').forEach(el => {
  observer.observe(el);
});

// 스무스 스크롤
document.querySelectorAll('a[href^="#"]').forEach(anchor => {
  anchor.addEventListener('click', function (e) {
    e.preventDefault();
    const target = document.querySelector(this.getAttribute('href'));
    if (target) {
      target.scrollIntoView({
        behavior: 'smooth',
        block: 'start'
      });
    }
  });
});
```
