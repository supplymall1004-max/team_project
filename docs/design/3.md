## 전체 레이아웃 구조

### 헤더 (Header)
- **위치**: 페이지 최상단 고정
- **구성 요소**:
  - 좌측: Hostinger 로고
  - 중앙: 메인 네비게이션 메뉴 (드롭다운)
  - 우측: 언어 선택, 계정 버튼
- **스타일**: 깔끔한 흰색 배경, 미니멀 디자인
- **고정 여부**: 스크롤 시 상단 고정 (Sticky Header)

### 메인 컨텐츠 영역
- **레이아웃**: 
  1. 브레드크럼 네비게이션
  2. 튜토리얼 헤더 (제목, 메타 정보)
  3. 목차 (Table of Contents) - 토글 가능
  4. 본문 콘텐츠
  5. 관련 튜토리얼 섹션
  6. 댓글 섹션
- **배경**: 흰색 배경, 섹션별 구분

### 푸터 (Footer)
- **구성**: 다중 컬럼 링크, 소셜 미디어, 결제 수단 아이콘
- **스타일**: 진한 배경, 흰색 텍스트

## 네비게이션 시스템

### 메인 네비게이션 구조
```
요금제 | 서비스 | 웹사이트 | VPS | 도메인 | 이메일 | 살펴보기 | 고객지원
```

### 드롭다운 메뉴 예시

#### 서비스 드롭다운
```
호스팅
├── 워드프레스 특화 관리형 호스팅 (AI)
├── 관리형 우커머스 특화 호스팅
├── 웹호스팅
├── 클라우드 호스팅
├── 에이전시 호스팅
└── Node.js 웹 앱 호스팅

웹사이트
├── 웹사이트 빌더 (AI)
├── 이커머스 웹사이트 빌더 (AI)
└── Horizons (AI)

VPS
├── VPS 호스팅
└── n8n VPS 호스팅

도메인
├── 도메인 네임 검색
└── 도메인 이전

이메일
├── Hostinger Reach (이메일 마케팅)
├── 비즈니스 이메일
└── 구글 워크스페이스
```

### 네비게이션 특징
- **메가 메뉴**: 대형 드롭다운으로 카테고리별 세부 항목 표시
- **아이콘/배지**: "인기", "AI" 등 배지로 특별 기능 강조
- **호버 효과**: 마우스 오버 시 드롭다운 메뉴 표시
- **반응형**: 모바일에서는 햄버거 메뉴로 전환

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const id = entry.target.getAttribute('id');
      document.querySelectorAll('.toc-list a').forEach(link => {
        link.classList.remove('active');

  });

  observer.observe(section);
