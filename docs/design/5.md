## 전체 레이아웃 구조

### 헤더 (Header)
- **위치**: 페이지 최상단 고정
- **구성 요소**:
  - 좌측: Wix 로고
  - 중앙/우측: 메인 네비게이션 메뉴
  - 우측: "웹사이트 제작하기" CTA 버튼
- **스타일**: 깔끔한 흰색 배경, 미니멀 디자인
- **고정 여부**: 스크롤 시 상단 고정 (Sticky Header)

### 메인 컨텐츠 영역
- **레이아웃**: 3열 구조
  - 좌측: 사이드바 (구독하기, 웹사이트 제작하기 등)
  - 중앙: 블로그 포스트 본문
  - 우측: 관련 링크 또는 광고 (선택사항)
- **배경**: 흰색 배경, 섹션별 구분

### 푸터 (Footer)
- **구성**: 다중 컬럼 링크, 회사 정보, 소셜 미디어
- **스타일**: 진한 배경, 흰색 텍스트

## 네비게이션 시스템

### 메인 네비게이션 구조
```
로고 | 블로그 카테고리 (드롭다운) | 웹사이트 제작하기
```

### 블로그 카테고리 메뉴
```
웹사이트 제작하기 (드롭다운)
├── 온라인 쇼핑몰
├── 온라인 마케팅
│   ├── 마케팅
│   ├── SNS
│   └── Google & SEO
├── 웹 디자인
├── 비즈니스 팁
├── 예술 & 포토그래피
├── Wix 업데이트 및 사용법
└── More
```

### 네비게이션 특징
- **드롭다운 메뉴**: 호버 시 하위 카테고리 표시
- **탭 네비게이션**: 키보드 Tab 키로 메뉴 이동 가능
- **활성 상태**: 현재 카테고리 강조 표시
- **반응형**: 모바일에서는 햄버거 메뉴로 전환

```javascript
// Intersection Observer로 스크롤 애니메이션
const observerOptions = {
  threshold: 0.1,
  rootMargin: '0px 0px -50px 0px'
};

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('fade-in');
    }
  });
}, observerOptions);

document.querySelectorAll('.example-item, .sidebar-section').forEach(el => {
```

```css
  transform: scale(1.2);
}

@keyframes fadeIn {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}
```
