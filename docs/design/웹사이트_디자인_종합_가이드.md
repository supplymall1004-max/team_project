## 웹사이트 유형별 분류

### 1. 랜딩 페이지 (Landing Page)
**특징**: 제품/서비스 소개, 강력한 CTA, 히어로 섹션 중심

**분석 사이트**:
- **Squarespace** (1.md) - 웹사이트 빌더 랜딩 페이지
- **Qshop.ai** (4.md) - AI 쇼핑몰 빌더 랜딩 페이지
- **Coworkerweb** (7.md) - 코워킹 스페이스 랜딩 페이지

**공통 패턴**:
- 히어로 섹션 (큰 제목 + CTA)
- 기능 소개 섹션 (3-4열 그리드)
- 고객 후기/신뢰성 섹션
- 최종 CTA 섹션

---

### 2. 템플릿 갤러리 (Template Gallery)
**특징**: 필터 시스템, 그리드 레이아웃, 무한 스크롤

**분석 사이트**:
- **아임웹** (2.md) - 템플릿 갤러리 페이지

**공통 패턴**:
- 카테고리 필터 바
- 템플릿 카드 그리드
- 무한 스크롤 또는 페이지네이션
- 템플릿 상세 모달

---

### 3. 블로그/콘텐츠 페이지 (Blog/Content)
**특징**: 콘텐츠 중심, 가독성 우선, 사이드바 네비게이션

**분석 사이트**:
- **Hostinger** (3.md) - 튜토리얼 페이지
- **Wix 블로그** (5.md) - 블로그 포스트 페이지

**공통 패턴**:
- 브레드크럼 네비게이션
- 목차(TOC) 시스템
- 본문 콘텐츠 레이아웃
- 관련 콘텐츠 추천
- 댓글 시스템

---

### 4. 커뮤니티 플랫폼 (Community Platform)
**특징**: 사용자 생성 콘텐츠, 투표 시스템, 댓글 스레드

**분석 사이트**:
- **Reddit** (6.md) - 소셜 미디어 플랫폼

**공통 패턴**:
- 3열 레이아웃 (사이드바 + 메인 + 사이드바)
- 포스트 카드 디자인

```javascript
// 필터 기능
function filterItems(category) {
  const items = document.querySelectorAll('.grid-item');
  const buttons = document.querySelectorAll('.filter-button');
  
  // 버튼 활성 상태 변경
  buttons.forEach(btn => {
    btn.classList.remove('active');
    if (btn.dataset.category === category) {
      btn.classList.add('active');
    }
  });
  
  // 아이템 필터링
  items.forEach(item => {
    const itemCategory = item.dataset.category;
    
    if (category === 'all' || itemCategory === category) {
      item.style.display = 'block';
      item.style.animation = 'fadeIn 0.5s ease';
    } else {
      item.style.display = 'none';
    }
  });
}

// 필터 버튼 이벤트
document.querySelectorAll('.filter-button').forEach(button => {
  button.addEventListener('click', function() {
    filterItems(this.dataset.category);
  });
});
```

```javascript
class Slider {
  constructor(container) {
    this.container = container;
    this.slides = container.querySelectorAll('.slider-slide');
    this.dots = container.querySelectorAll('.dot');
    this.currentIndex = 0;
    this.init();
  }
  
  init() {
    this.showSlide(this.currentIndex);
    this.setupControls();
    this.autoSlide();
  }
  
  showSlide(index) {
    this.slides.forEach((slide, i) => {
      slide.style.display = i === index ? 'block' : 'none';
    });
    
    this.dots.forEach((dot, i) => {
      dot.classList.toggle('active', i === index);
    });
  }
  
  nextSlide() {
    this.currentIndex = (this.currentIndex + 1) % this.slides.length;
    this.showSlide(this.currentIndex);
  }
  
  prevSlide() {
    this.currentIndex = (this.currentIndex - 1 + this.slides.length) % this.slides.length;
    this.showSlide(this.currentIndex);
  }
  
  goToSlide(index) {
    this.currentIndex = index;
    this.showSlide(this.currentIndex);
  }
  
  setupControls() {
    const nextBtn = this.container.querySelector('.slider-next');
    const prevBtn = this.container.querySelector('.slider-prev');
    
    if (nextBtn) nextBtn.addEventListener('click', () => this.nextSlide());
    if (prevBtn) prevBtn.addEventListener('click', () => this.prevSlide());
    
    this.dots.forEach((dot, i) => {
      dot.addEventListener('click', () => this.goToSlide(i));
    });
  }
  
  autoSlide() {
    setInterval(() => {
      this.nextSlide();
    }, 5000);
  }
}
```

```javascript
const observerOptions = {
```

### 3. 이미지 Lazy Loading
```javascript
if ('IntersectionObserver' in window) {
  const imageObserver = new IntersectionObserver((entries, observer) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        const img = entry.target;
        img.src = img.dataset.src;
        img.classList.remove('lazy');
        observer.unobserve(img);
      }
    });
  });
  
  document.querySelectorAll('img[data-src]').forEach(img => {
    imageObserver.observe(img);
  });
}
```

### 4. 무한 스크롤
```javascript
let isLoading = false;
let currentPage = 1;

function loadMoreItems() {
  if (isLoading) return;
  
  isLoading = true;
  const loadingIndicator = document.createElement('div');
  loadingIndicator.className = 'loading-indicator';
  loadingIndicator.textContent = '로딩 중...';
  document.querySelector('.items-container').appendChild(loadingIndicator);
  
  fetch(`/api/items?page=${currentPage}`)
    .then(response => response.json())
    .then(data => {
      appendItems(data.items);
      currentPage++;
      isLoading = false;
      loadingIndicator.remove();
    })
    .catch(error => {
      console.error('Error:', error);
      isLoading = false;
      loadingIndicator.remove();
    });
}

window.addEventListener('scroll', () => {
  const scrollHeight = document.documentElement.scrollHeight;
  const scrollTop = document.documentElement.scrollTop;
  const clientHeight = document.documentElement.clientHeight;
  
  if (scrollTop + clientHeight >= scrollHeight - 1000) {
    loadMoreItems();
  }
});
```

```javascript
// 헤더 스크롤 효과
window.addEventListener('scroll', function() {

const mobileMenuToggle = document.querySelector('.mobile-menu-toggle');

document.querySelectorAll('a[href^="#"]').forEach(anchor => {

    if (target) {
      target.scrollIntoView({
```
