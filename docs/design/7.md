## 전체 레이아웃 구조

### 헤더 (Header)
- **위치**: 페이지 최상단 고정
- **구성 요소**:
  - 좌측: 로고/브랜드명
  - 중앙/우측: 메인 네비게이션 메뉴
  - 우측: 로그인, 예약하기 버튼
- **스타일**: 깔끔한 흰색 배경, 미니멀 디자인
- **고정 여부**: 스크롤 시 상단 고정 (Sticky Header)

### 메인 컨텐츠 영역
- **레이아웃**: 섹션 기반 세로 스크롤 구조
  1. 히어로 섹션 (Hero Section)
  2. 서비스 소개 섹션
  3. 공간 갤러리 섹션
  4. 시설 및 편의시설 섹션
  5. 가격/요금제 섹션
  6. 예약 시스템
  7. 위치 및 지도 섹션
  8. 고객 후기 섹션
- **배경**: 흰색/연한 회색 교차 사용

### 푸터 (Footer)
- **구성**: 다중 컬럼 링크, 연락처 정보, 소셜 미디어
- **스타일**: 진한 배경, 흰색 텍스트

```javascript
// 공간 필터 기능
function filterSpaces(category) {
  const spaces = document.querySelectorAll('.space-card');
  const buttons = document.querySelectorAll('.filter-button');
  
  // 버튼 활성 상태 변경
  buttons.forEach(btn => {
    btn.classList.remove('active');
    if (btn.dataset.category === category) {
      btn.classList.add('active');
    }
  });
  
  // 공간 필터링
  spaces.forEach(space => {
    const spaceCategory = space.dataset.category;
    
    if (category === 'all' || spaceCategory === category) {
      space.style.display = 'block';
      space.style.animation = 'fadeIn 0.5s ease';
    } else {
      space.style.display = 'none';
    }
  });
}

// 필터 버튼 이벤트
document.querySelectorAll('.filter-button').forEach(button => {
  button.addEventListener('click', function() {
    filterSpaces(this.dataset.category);
  });
});
```

// 모바일 메뉴 토글
document.querySelector('.mobile-menu-toggle').addEventListener('click', function() {
  document.querySelector('.nav-menu').classList.toggle('active');
  this.classList.toggle('active');
});

// 스크롤 시 헤더 스타일 변경
window.addEventListener('scroll', function() {
  const header = document.querySelector('.header');
  if (window.scrollY > 100) {
    header.classList.add('scrolled');
  } else {
    header.classList.remove('scrolled');
  }
});

// 스무스 스크롤
document.querySelectorAll('a[href^="#"]').forEach(anchor => {
  anchor.addEventListener('click', function(e) {
    e.preventDefault();
    const target = document.querySelector(this.getAttribute('href'));
    if (target) {
      target.scrollIntoView({
        behavior: 'smooth',
        block: 'start'
      });
    }
  });
});

// 예약 폼 제출
document.querySelector('.booking-form').addEventListener('submit', function(e) {
  e.preventDefault();
  
  const formData = new FormData(this);
  
  fetch('/api/booking', {
    method: 'POST',
    body: formData
  })
  .then(response => response.json())
  .then(data => {
    if (data.success) {
      alert('예약이 완료되었습니다!');
      this.reset();
    }
  })
  .catch(error => {
    console.error('Error:', error);
    alert('예약 중 오류가 발생했습니다.');
  });
});

// 이미지 갤러리 초기화
initImageGallery();

// 필터 기능 초기화
document.querySelectorAll('.filter-button').forEach(button => {
  button.addEventListener('click', function() {
    filterSpaces(this.dataset.category);
  });
});

// 스크롤 애니메이션 초기화
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('fade-in');
    }
  });
}, {
  threshold: 0.1,
  rootMargin: '0px 0px -50px 0px'
});

document.querySelectorAll('.service-card, .space-card, .pricing-card').forEach(el => {
  observer.observe(el);
});
