## 개요

Django Care 홈 화면에 **매일 변하는 콘텐츠**와 **개인화 추천** 기능을 추가하여 사용자의 재방문을 유도하고 습관 형성을 돕는 시스템입니다.

### 주요 목표

- ✅ 매일 오게 만들기 (연속 방문 일수 추적)
- ✅ 새로운 콘텐츠 발견의 즐거움 (오늘의 건강 상식)
- ✅ 사회적 증거 강화 (실시간 인기 순위)
- ✅ 커뮤니티 활성화 (최근 활동 피드)

### 기술 스택

- **Frontend**: React 19, Next.js 15, Tailwind CSS v4, Framer Motion
- **Backend**: Next.js API Routes, Server Actions
- **Database**: Supabase PostgreSQL
- **Authentication**: Clerk

## 구현된 기능

### 1. 맞춤 인사말 헤더

**파일**: `components/home/today-header.tsx`

#### 기능
- 시간대별 인사말 (아침/오후/저녁)
- 연속 방문 일수 (스트릭) 표시
- 오늘 날짜 표시
- 7일 이상 연속 방문 시 특별 아이콘 (✨)

#### 디자인
- 그라데이션 배경 (purple → pink → rose)
- 배경 패턴 (radial-gradient dots)
- 연속 방문 카드 (백드롭 블러 효과)
- 손 흔드는 애니메이션 👋

#### 사용 예시
```tsx
import { TodayHeader } from "@/components/home/today-header";

<TodayHeader />
```

---

### 2. 오늘의 추천 섹션

**파일**: `components/home/daily-recommendations-section.tsx`

#### 기능
- **오늘의 건강 상식**: 15개 상식 중 날짜 기반 로테이션
- **오늘의 인기 레시피 TOP 5**: 최근 조회수 기반
- **나만을 위한 추천**: 로그인 시 개인화 추천

#### 디자인
- 건강 상식: 파란색 그라데이션 카드
- 인기 레시피: 그리드 레이아웃 (1/2/3 컬럼)
- 개인화 추천: 핑크 테마 카드
- 카드 hover 시 확대 + 그림자 효과

#### 사용 예시
```tsx
import { DailyRecommendationsSection } from "@/components/home/daily-recommendations-section";

<DailyRecommendationsSection />
```

## 사용 방법

### 홈 화면에 섹션 추가하기

새 섹션은 자동으로 홈 화면에 추가됩니다. 순서를 변경하려면:

**파일**: `types/home-customization.ts`

```typescript
export const DEFAULT_HOME_CUSTOMIZATION: HomeCustomization = {
  theme: {
    mode: 'light',
    backgroundType: 'gradient',
  },
  sectionOrder: [
    'emergency-quick-access',
    'weather-widget',
    'today-header',              // 맞춤 인사말
    'daily-recommendations',      // 오늘의 추천
    'trending-section',          // 트렌딩
    'hero-section',
    'recent-activity-feed',      // 최근 활동
    'community-preview',
  ],
  version: '1.1.0',
};
```

### 섹션 숨기기

특정 섹션을 숨기려면 `sectionOrder` 배열에서 해당 ID를 제거하면 됩니다.

## API 문서

### 1. 사용자 통계 API

**엔드포인트**: `GET /api/user/stats`

**인증**: 필수 (Clerk)

**응답**:
```json
{
  "name": "홍길동",
  "streakCount": 7,
  "totalVisits": 15
}
```

**설명**:
- 연속 방문 일수 자동 계산
- 오늘 첫 방문 시 자동 기록
- 하루 빠지면 스트릭 리셋

---

### 2. 오늘의 콘텐츠 API

**엔드포인트**: `GET /api/content/daily`

**인증**: 선택 (로그인 시 개인화 추천 제공)

**응답**:
```json
{
  "healthTip": {
    "title": "물 마시기",
    "content": "하루 8잔의 물을...",
    "icon": "💧",
    "category": "nutrition"
  },
  "popularRecipes": [
    {
      "id": "uuid",
      "title": "김치찌개",
      "image": "https://...",
      "category": "한식",
      "calories": 350
    }
  ],
  "personalizedRecipes": [...]
}
```

---

### 3. 트렌딩 레시피 API

**엔드포인트**: `GET /api/trending/recipes?limit=10`

**인증**: 불필요

**쿼리 파라미터**:
- `limit`: 조회할 레시피 수 (기본값: 10)

**응답**:
```json
{
  "recipes": [
    {
      "id": "uuid",

      "image": "https://...",
      "trending": {
        "viewCount": 1234,
        "likeCount": 56,
        "saveCount": 23,
        "popularityScore": 450
      }
    }
  ]
}
```

## 데이터베이스 스키마

### 1. user_daily_visits

사용자 일일 방문 기록

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID | Primary Key |
| user_id | UUID | 사용자 ID (FK) |
| visit_date | DATE | 방문 날짜 |
| streak_count | INTEGER | 연속 방문 일수 |
| total_visits | INTEGER | 총 방문 일수 |
| created_at | TIMESTAMPTZ | 생성 시간 |

**인덱스**:
- `idx_user_daily_visits_user_date` (user_id, visit_date DESC)
- `idx_user_daily_visits_streak` (user_id, streak_count DESC)

---

### 2. daily_health_tips

오늘의 건강 상식

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID | Primary Key |
| title | TEXT | 제목 |
| content | TEXT | 내용 |
| category | TEXT | 카테고리 (nutrition, exercise, sleep, mental) |
| icon | TEXT | 이모지 |
| source | TEXT | 출처 |
| difficulty | TEXT | 난이도 |
| is_active | BOOLEAN | 활성화 여부 |
| display_order | INTEGER | 표시 순서 |
| created_at | TIMESTAMPTZ | 생성 시간 |

**기본 데이터**: 15개 건강 상식 포함

---

### 3. user_behavior_logs

사용자 행동 로그

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID | Primary Key |
| user_id | UUID | 사용자 ID (FK) |
| action_type | TEXT | 행동 유형 (view, like, save, search, cook) |
| target_type | TEXT | 대상 유형 (recipe, post, diet, health_tip) |
| target_id | UUID | 대상 ID |
| metadata | JSONB | 추가 정보 |
| created_at | TIMESTAMPTZ | 생성 시간 |

**인덱스**:
- `idx_user_behavior_user_action` (user_id, action_type, created_at DESC)
- `idx_user_behavior_target` (target_type, target_id, created_at DESC)
- `idx_user_behavior_recent` (user_id, created_at DESC) WHERE created_at > NOW() - INTERVAL '30 days'

## 트러블슈팅

### 문제: 연속 방문 일수가 표시되지 않음

**원인**: 마이그레이션이 적용되지 않았거나 API 호출 실패

**해결**:
1. 마이그레이션 확인: `supabase db push`
2. 브라우저 콘솔에서 API 응답 확인
3. Supabase 대시보드에서 `user_daily_visits` 테이블 확인

---

### 문제: 건강 상식이 표시되지 않음

**원인**: 기본 데이터가 삽입되지 않음

**해결**:
```sql
-- Supabase SQL Editor에서 실행
SELECT COUNT(*) FROM daily_health_tips WHERE is_active = TRUE;
```

결과가 0이면 마이그레이션 파일을 다시 실행하세요.

---

### 문제: 트렌딩 섹션이 비어있음

**원인**: 레시피 데이터가 없거나 API 오류

**해결**:
1. 레시피 데이터 확인: `SELECT COUNT(*) FROM recipes;`
2. API 로그 확인: 브라우저 콘솔 또는 서버 로그
3. 임시로 샘플 데이터 추가

---

### 문제: 애니메이션이 느림

**원인**: 너무 많은 애니메이션 동시 실행

**해결**:
1. `delay` 값 조정하여 순차 실행
2. `transition.duration` 값 줄이기
3. 불필요한 애니메이션 제거
